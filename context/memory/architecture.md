# Architecture Summary — GTA VI: Cali

- **ADR-001**: Headless simulation (`src/simulation/`) and mission director (`src/missions/`) import ONLY `src/types/` and `src/config/`; zero `three` or DOM dependencies.
- **Map Single Source of Truth**: `src/config/caliMap.ts` exports `CALI_MAP` (`-240..+240`), `getTerrainElevation(x, z)` (C1-smooth Cerro Los Cristales climb to 22m + San Antonio terrace), Río Cali + twin bridges (`Puente La Ermita`, `Puente Bulevar Sur`), 6 landmarks, 33 buildings, 16 roads, 3 traffic routes, and 4 police spawns.
- **Presentation & Audio**: `src/world/worldRenderer.ts` consumes readonly `WorldSnapshot` + `MissionSnapshot` (zero mutations, clean `WebGLUnavailableError`), loading ~30 MB local `public/` CC0/MIT assets via `assetLoader.ts` (`ferrari.glb`, Morena `valeria.glb`, realistic Caleño `caleno.glb`, `character.glb` clip donor, golden-hour `.hdr` HDRI PMREM skybox/IBL, 10 1K photo PBR sets, local JS Draco), mounting sculpted clearcoat Colombian vehicles w/ solid roofs, smoked glass, Colombian license plates, 512px Cali jerseys, stunt ramps, *Latonería* bays, Cholado stands, working traffic lights, murals, and `★★★` roadblocks (`vehicleMeshes.ts`, `caliLandmarks.ts`), GPU `ParticleSystem` (exhaust backfire) + `SkidMarkPool` (`particles.ts`), `EffectComposer` (`RenderPass -> UnrealBloomPass -> highlight-safe CinematicGradePass -> SMAAPass -> OutputPass`) + `2048px` shadows (`sceneSetup.ts`), and full GPU/mixer/texture cleanup (`disposeObjectTree()`). `src/audio/audioEngine.ts` + `src/audio/voiceEngine.ts` synthesize 5-speed V8/turbo BOV/diesel telemetry, `[H]` horn & Chiva *"La Cucaracha"*, Pay 'n' Spray/stunt/crash foley, Doppler Wail/Yelp sirens, Salsa/Synth radio, and offline `es-CO` Web Speech API dialogues/callouts.
- **Runtime Root**: `src/game/gameApp.ts` clamps `dt <= 0.05s`, wires `InputManager`, `HudController`, `MinimapRenderer`, and exposes readonly `window.__GTA_CALI__` for E2E verification.
