# Architecture Summary — GTA VI: Cali

- **ADR-001**: Headless simulation (`src/simulation/`) and mission director (`src/missions/`) import ONLY `src/types/` and `src/config/`; zero `three` or DOM dependencies.
- **Map Single Source of Truth**: `src/config/caliMap.ts` exports `CALI_MAP` (`-240..+240`), `getTerrainElevation(x, z)` (C1-smooth Cerro Los Cristales climb to 22m + San Antonio terrace), Río Cali + twin bridges (`Puente La Ermita`, `Puente Bulevar Sur`), 6 landmarks, 33 buildings, 16 roads, 3 traffic routes, and 4 police spawns.
- **Presentation & Audio**: `src/world/worldRenderer.ts` consumes readonly `WorldSnapshot` + `MissionSnapshot` (zero mutations, clean `WebGLUnavailableError`), asynchronously loading 25 MB local `public/` CC0/MIT assets via `assetLoader.ts` (`ferrari.glb`, rigged `character.glb` + `AnimationMixer`, golden-hour `.hdr` HDRI PMREM skybox/IBL, 10 1K photo PBR sets, local JS Draco), paired with `pbrTextures.ts` (GLSL Río Cali water + fallbacks), GPU `ParticleSystem` (`particles.ts`), `EffectComposer` + subtle HDR `UnrealBloomPass` + `2048px` shadows + GTA V free-orbit mouse camera (`sceneSetup.ts`, `InputManager`), and full `disposeObjectTree()` GPU cleanup; `src/audio/audioEngine.ts` synthesizes Salsa Brava 98.5 FM, Sucursal Synth 104.3 FM, engine RPM, siren, and SFX with injectable `AudioContextFactory`.
- **Runtime Root**: `src/game/gameApp.ts` clamps `dt <= 0.05s`, wires `InputManager`, `HudController`, `MinimapRenderer`, and exposes readonly `window.__GTA_CALI__` for E2E verification.
