# Architecture Summary — GTA VI: Cali

- **ADR-001**: Headless simulation (`src/simulation/`) and mission director (`src/missions/`) import ONLY `src/types/` and `src/config/`; zero `three` or DOM dependencies.
- **Map Single Source of Truth**: `src/config/caliMap.ts` exports `CALI_MAP` (`-240..+240`), `getTerrainElevation(x, z)` (C1-smooth Cerro Los Cristales climb to 22m + San Antonio terrace), Río Cali + twin bridges (`Puente La Ermita`, `Puente Bulevar Sur`), 6 landmarks, 33 buildings, 16 roads, 3 traffic routes, and 4 police spawns.
- **Presentation & Audio**: `src/world/worldRenderer.ts` consumes readonly `WorldSnapshot` + `MissionSnapshot` (zero mutations, clean `WebGLUnavailableError`), asynchronously loading 28 MB local `public/` CC0/MIT assets via `assetLoader.ts` (`ferrari.glb`, Morena Caleña `valeria.glb` retargeted via `SkeletonUtils.retargetClip` + `SambaDance`, `character.glb`, golden-hour `.hdr` HDRI PMREM skybox/IBL, 10 1K photo PBR sets, local JS Draco), paired with 3D facade relief/street props/wet puddles/high-craft landmarks (`caliLandmarks.ts`), GPU `ParticleSystem` + pooled `SkidMarkPool` (`particles.ts`), `EffectComposer` (`RenderPass -> UnrealBloomPass -> highlight-safe CinematicGradePass -> SMAAPass -> OutputPass`) + `2048px` shadows + GTA V free-orbit mouse camera (`sceneSetup.ts`, `InputManager`), and full GPU/mixer cleanup (`disposeObjectTree()`). `src/audio/audioEngine.ts` + `src/audio/voiceEngine.ts` synthesize 5-speed V8/diesel engine telemetry, drift screech, collision foley, distance/Doppler Wail/Yelp sirens, radio squelch, Cali street murmur, Salsa/Synth radio, and offline `es-CO` Web Speech API dialogues/callouts with injectable factories.
- **Runtime Root**: `src/game/gameApp.ts` clamps `dt <= 0.05s`, wires `InputManager`, `HudController`, `MinimapRenderer`, and exposes readonly `window.__GTA_CALI__` for E2E verification.
